# 个人主页 + 作品集 设计方案

日期：2026-10-15
仓库：`HDNRAY.github.io`（GitHub Pages 根站）
状态：已实现并验证

## 背景

根 `index.html` 原本是一个「项目索引页」：用 GitHub API 扫描仓库目录，自动列出子项目。
它有三个问题：

1. 没有任何个人信息，无法作为个人主页。
2. 依赖 GitHub API（未认证 60 次/小时），限流时只能退化成硬编码列表。
3. 展示不可控——标题靠抓取子页面 `<title>`，样式无法按作品重要性排序。

目标：改造成**个人主页 + 个人作品展示**，简约风格，纯 CSS 动态效果，零依赖零构建。

## 技术形态

**单文件静态页**：保留 `index.html`，内联全部 CSS 与 JS。

- 理由：GitHub Pages 根站，单文件无构建产物、无 CI 依赖，改完 push 即生效；不存在多文件带来的收益。
- 已否决的方案：
  - 拆成 `styles.css` + `main.js`：当前规模（单页、约 60KB）没有拆分价值，反而增加请求数与维护面。
  - 引入 Tailwind / 组件库：给一个静态介绍页加构建链，成本远大于收益。
- 四个作品目录（`bdgame/`、`codelinez/`、`colorguess/`、`raid/`）完全不动，只重写根 `index.html`。
- 删除 GitHub API 动态扫描，作品改为静态手写——展示可控、永不空白、无外部请求。

## 视觉风格

| 项 | 方案 |
|---|---|
| 主色 | 靛蓝 `#4f46e5` → 青 `#06b6d4` 渐变点缀，粉 `#f472b6` 作第三色 |
| 背景 | 深色 `#0f1117` 为默认，`prefers-color-scheme: light` 自动切浅色 `#f7f8fb` |
| 字体 | 系统字体栈（含 PingFang SC / 微软雅黑），正文 16px / 行高 1.7 |
| 版心 | 最大 880px 居中，区块上下留白 84px |
| 卡片 | 1px 细边框 + 14px 圆角；悬停上浮 3–4px、边框转向主色 |

设计 token 全部收敛为 `:root` 的 CSS 变量，浅色为基准、深色用媒体查询覆盖，因此新增区块只要复用
变量就自动适配两套配色。

## 动态效果（全部纯 CSS）

| 效果 | 实现 |
|---|---|
| Hero 柔光漂移 | 3 层 `radial-gradient` + `filter: blur(70px)`，`drift` 关键帧 20s 往复 |
| 姓名渐变流光 | `background-clip: text` + `background-size: 200%`，`shift` 关键帧 |
| 状态圆点呼吸 | `pulse`（box-shadow 扩散）+ 工作室圆点的 `halo` 环形扩散 |
| 向下箭头 | `bob` 上下浮动 + 透明度呼吸 |
| 导航下划线 | `::after` + `transform: scaleX()`，`transform-origin: left` 自绘展开 |
| 作品卡下划线 | 同上，但用 `::after` 绝对定位在卡片底部、带 0.42s 缓动 |
| 滚动淡入 | `IntersectionObserver` 加 `.in` 类，29 个 `.reveal` 元素错峰入场（`data-delay` 0–5 级） |
| 时间线节点 | 悬停放大 + 主色光晕 |

### 无障碍与降级（关键设计决策）

滚动淡入是唯一依赖 JS 的效果，因此做了三重保险，避免「JS 没跑 → 整页空白」这类经典事故：

1. `html.js` 标记由内联脚本**在 `<head>` 里同步置位**，`.reveal` 的初始隐藏态只在 JS 可用时生效；无 JS 时内容始终可见。
2. 不支持 `IntersectionObserver` 时直接全部显示。
3. `beforeprint` 事件与「页面处于后台 2.5s」两条兜底路径也会全部显示——覆盖打印、后台标签页打开、observer 被浏览器节流等场景。

`@media (prefers-reduced-motion: reduce)` 会把所有动画与过渡压到 0.001ms 并直接显示全部内容。

## 响应式

断点 720px：

- Hero 身份标签由横向药丸改为**左对齐竖排**（横排时中间的分隔竖线会落到行尾，视觉很怪）。
- 教育卡片、工作经历改为单列，年份换行独占一行。
- 时间线轴与节点内移并缩小。
- 顶部导航品牌文字隐藏只留圆点；导航链接容器改为可横向滚动（`联系` 需滑动才能看到，末端留 6px 呼吸位）。
- 所有锚点目标设 `scroll-margin-top: 76px`，确保固定导航（58px）不会盖住标题。

## 验证记录

用本地 `python3 -m http.server` + Playwright（Chromium）在 1280×900 与 390×844 两种视口、
浅色与深色两套配色下实测：

- HTML 标签闭合无误、CSS 花括号平衡（156/156）、无失效锚点、所有引用资源 200。
- 4 张网页卡与 2 个二维码图片均实际加载（`naturalWidth` = 430）。
- 29 个 `.reveal` 元素滚动后全部进入 `.in` 状态。
- 无控制台报错、无失败请求。
- 横向无溢出：`scrollWidth === clientWidth`（1280 / 390）；Hero 光晕虽溢出但在 `overflow-x: clip` 内裁掉。
- 7 个锚点跳转后目标 `top` 均为 76px，稳定位于固定导航下方；移动端导航滚动后 `联系` 完整可见（right 372 < 390）。
- 深浅两套配色下 `body` 背景与文字色按预期切换。
